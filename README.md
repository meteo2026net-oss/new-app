# طقس MCNC (MCNC Weather) 🌦️🇸🇾
### التطبيق الرسمي للمركز الوطني للأرصاد الجوية والمناخ في الجمهورية العربية السورية

تطبيق متطور وعالي الدقة يوفر توقعات الطقس الآنية والمستقبلية لجميع المحافظات السورية والعالم، مع ربط مباشر بشبكة محطات الرصد السورية الرسمية ونظام الإنذار المبكر (CAP) والنشرات الجوية الصوتية.

---

## 📦 النسختان المتوفرتان في هذا المشروع (Two Implementations)

تم إعداد نسختين متطابقتين تماماً من التطبيق بجميع المزايا والتصميم:

### 1️⃣ النسخة الأولى: Native Android (Kotlin + Jetpack Compose)
- **الموقع**: في المجلد الرئيسي ومجلد `app/`
- **التقنيات**: Kotlin 2.2+, Jetpack Compose, Material Design 3, Coroutines, StateFlow, Retrofit, Moshi.
- **التشغيل والمحاكي**: جاهزة ومثبتة وتعمل مباشرة على المحاكي السحابي في Google AI Studio، وتجتاز اختبارات Robolectric Unit Tests.

### 2️⃣ النسخة الثانية: Flutter (Cross-Platform Android, iOS, Web)
- **الموقع**: في المجلد `flutter_meteo_weather/`
- **التقنيات**: Flutter 3+, Dart, Material 3, Dark Glassmorphism, Arabic RTL Localization, Open-Meteo REST API, Flutter TTS.
- **التشغيل**:
  ```bash
  cd flutter_meteo_weather
  flutter pub get
  flutter run
  ```

## 🌟 الميزات المشتركة بين النسختين (Features)

1. **شبكة محطات الرصد السورية (13 محطة رسمية)**:
   - دمشق الدولي، حلب الدولي، اللاذقية البحرية، حمص المركزية، طرطوس الميناء، حماة الزراعية، دير الزور، القامشلي، السويداء، درعا، إدلب، الرقة، وتدمر الأثرية.
   - قراءات حية لدرجات الحرارة، الرطوبة، سرعة الرياح والضغط الجوي، مع شارة الاتصال الحي (أونلاين).
2. **منظومة التنبيهات الجوية المبكرة (CAP Alerts)**:
   - تنبيهات العواصف الرعدية، موجات الحر، الرياح الشديدة، والأمطار الغزيرة وفق بروتوكول الإنذار المشترك مع إرشادات السلامة للمواطنين.
3. **النشرة الجوية الصوتية (Audio Bulletin)**:
   - إذاعة النشرة الجوية الصباحية والمسائية بصوت المذيع الآلي مع شريط تقدم وتحكم بالتشغيل والإيقاف.
4. **توقعات الطقس الدقيقة (Open-Meteo API)**:
   - توقعات ساعية لـ 24 ساعة قادمة.
   - توقعات تفصيلية لـ 7 أيام قادمة مع مؤشرات الحرارة العظمى والصغرى وفرص الأمطار.
5. **لوحة المؤشرات البيئية والجوية (8 مؤشرات)**:
   - الرطوبة، سرعة واتجاه الرياح، الضغط الجوي، مؤشر الأشعة فوق البنفسجية (UV)، جودة الهواء (AQI)، الرؤية الأفقية، الحرارة المحسوسة، وحبوب اللقاح.
   - إمكانية تخصيص وترتيب البطاقات وإخفاء/إظهار المؤشرات.
6. **خريطة الرادار الجوي السوري التفاعلية**:
   - عرض المحطات السورية على الخريطة مع درجات الحرارة وطبقة رادار الأمطار.
7. **مساعد طقس MCNC الذكي (AI Meteorological Assistant)**:
   - مساعد تفاعلي يجيب عن أسئلة الطقس، نصائح اللباس، مواعيد السفر بين المحافظات، والإرشادات الزراعية للمحاصيل.
8. **لوحة تحكم الأرصاد السورية (Admin Dashboard)**:
   - واجهة مخصصة للمتنبئين الجويين لإصدار تنبيهات CAP وتحديث النشرة الصوتية.
9. **واجهة عربية أصيلة (RTL)** وتصميم زجاجي ليلي مريح للعين (Dark Glassmorphism).

## 🚀 كيفية رفع المشروعين إلى جيت هاب (How to Push to GitHub)

### الطريقة الأولى: من خلال واجهة Google AI Studio مباشرة (موصى بها)
1. اضغط على قائمة الإعدادات (Settings / Share) في الزاوية العلوية لمنصة AI Studio.
2. اختر **"Push to GitHub"** أو **"Export to GitHub"**.
3. قم بتسجيل الدخول بحسابك واختيار المستودع `meteo2026net-oss/meteo-wheather` أو مستودع جديد، وسيتم رفع النسختين (نسخة كوتلن ونسخة فلاتر داخل مجلد `flutter_meteo_weather/`).

### الطريقة الثانية: عبر سطر الأوامر (Git CLI)
إذا قمت بتنزيل المشروع كملف ZIP إلى جهازك:
```bash
# 1. الدخول للمجلد
cd meteo-weather

# 2. إضافة التغييرات والالتزام
git add .
git commit -m "إضافة نسختي كوتلن وفلاتر المتطابقتين لتطبيق طقس MCNC"

# 3. الرفع إلى مستودع جيت هاب
git remote set-url origin https://github.com/meteo2026net-oss/meteo-wheather.git
git push origin main
```

إذا أردت رفع نسخة فلاتر كمستودع مستقل بذاته:
```bash
cd flutter_meteo_weather
git init
git add .
git commit -m "Initial commit for Flutter MCNC Weather App"
git remote add origin <رابط_مستودع_فلاتر_الخاص_بك>
git branch -M main
git push -u origin main
```
