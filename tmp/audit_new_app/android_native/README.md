# تطبيق طقس MCNC - نسخة Android Native (Kotlin) 🇸🇾

تطبيق أندرويد أصيل مبني بأحدث التقنيات الرسمية لتقديم توقعات الطقس وتنبيهات الإنذار المبكر وشبكة محطات الرصد السورية.

## 🛠️ متطلبات التشييد
- Android SDK (API 34 / Android 14)
- JDK 17+
- Gradle Wrapper

## 🚀 التشغيل والاختبار
```bash
# بناء نسخة التجربة (Debug APK)
./gradlew :app:assembleDebug

# تشغيل اختبارات الوحدات المحلية (Robolectric)
./gradlew :app:testDebugUnitTest
```
