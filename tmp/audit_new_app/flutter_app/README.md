# تطبيق طقس MCNC - نسخة Flutter (Cross-Platform) 🇸🇾

تطبيق فلاتر عابر للمنصات (أندرويد، iOS، ويب) يعتمد على لغة Dart وواجهات الماتيريال 3 المظلمة الزجاجية.

## 🛠️ متطلبات التشييد
- Flutter SDK >= 3.0.0
- Dart SDK >= 3.0.0

## 🚀 التشغيل والاختبار
```bash
# جلب الحزم والاعتماديات
flutter pub get

# فحص كود Dart وتدقيق الواجهات
flutter analyze

# تشغيل اختبارات الوحدات (Unit Tests)
flutter test

# تشغيل التطبيق
flutter run
```
